# Generative design of PPI inhibitors

A two-person machine learning project: an adversarial autoencoder and LatentGAN trained on the iPPI-DB database of protein-protein interaction inhibitors \(n=2378\), comparing four molecule representations and using docking scores as activity. The drive holds the proposal, the compound tables in several cleaned versions, a candidate list, the project deck and report, and the papers it follows. It reads as finished course work that could become a paper.
